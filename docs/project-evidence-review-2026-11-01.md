# 추가 자료 검토와 포트폴리오 반영

## 한화솔루션 ESH

- 사용자 확인: Spring Framework 기반 백엔드가 주 담당이며 일부 Vue.js 화면 개발 병행. 개요·역할·결과를 이에 맞게 수정.
- [한화솔루션 공식 블로그 「ESH가 뭐야?」](https://www.chemidream.com/2621)는 2020-08-13 게시 자료. 환경·안전·보건과 PSM·MoC 업무의 포털 맥락을 확인하는 데 사용.
- 원문에 공개된 PSM 추적·MoC 목록·수행 화면 이미지를 출처·저작권과 함께 원본 그대로 연결. 소개 시점이 참여 기간(2021.03~05)보다 앞선다는 점 명시.
- MoC·PSM의 세부 기능을 본인이 모두 개발했다고 추가하지 않음. 직접 담당한 모듈은 아직 미확인.

## UBASE

- 제공된 2023년 목표수립 매뉴얼 11페이지 검토. PDF 9~10페이지에서 목표 등록, 요소별 비율 합계, 직전 목표 가져오기, 전송·전송 취소, 목표별 행동지표 작성·저장·수정 확인.
- 매뉴얼을 바탕으로 서비스 기능 요약과 별도의 기능 도식 추가. 원본의 실명·접속 안내·화면 이미지는 게시하지 않음.
- 2021년의 개인 수행 내용은 기존에 확인된 메뉴 로직 개편과 평가 이력 관리로 유지. 2023년의 기능 모두를 2021년 개인 구현 성과로 소급하지 않음.
- 매뉴얼만으로 평가 이력의 저장 시점·키·변경 규칙이나 기존 로직의 문제는 확인할 수 없음. 해당 사항은 추가 기억·자료가 있을 때 보강.

## 차세대 지방재정 Open API

보관 중인 Python 스크립트 4개를 정적으로 검토했으며 외부 API·DB 접속이나 원본 스크립트 실행은 하지 않음.

- 엑셀 지표 목록에서 생성 대상으로 표시한 항목만 선택.
- 일·월·분기·반기·연 단위의 시점을 순회하며 데이터 수집. 미래 지표의 조회 종료 시점을 별도로 관리하는 코드도 확인.
- KOSIS JSON 정규화와 ECOS `StatisticSearch.row` 추출을 분리.
- 4만 셀 초과 조회 대응용 스크립트에서 KOSIS 분류 항목을 나누어 수집하는 구현 확인. 이는 당시 보관 코드의 처리 대상이며 현행 API 제한을 새로 조사한 결론은 아님.
- 데이터 없는 시점 건너뛰기, 일부 조회 오류의 파라미터 보정, 지표별 오류 목록과 성공·실패 집계 확인.
- 응답 병합 및 UTF-8 BOM CSV 출력 확인. 버전에 따라 지표 ID·주기를 파일명으로 사용.

포트폴리오의 문제·실행·결과와 수집 도식에 반영. CSV 생성과 이후 DB 초기 적재·ETL 연계 단계를 구분. 원본에 접속·인증 관련 정보가 있어 코드·엑셀·설정 파일 원문은 공개하지 않음. 당시 초기 수집·POC 스크립트이므로 운영 스케줄링, 재시도 정책, 멱등성까지 구현한 운영 파이프라인으로 설명하지 않음.

## Pop Talk

제공된 압축 로그 5개는 JSON Lines 형식. 중복된 수집 기록이 있으며 요청별 고유 식별자가 모든 기록에 있는 것은 아니므로 전체 성공률·정확도·지연 통계를 산출하지 않음. 원문 요청과 대화는 인용하지 않고 처리 상태만 요약.

2026-08-14 실행에서 다음 흐름 확인:

1. `insufficient_evidence`, `retry_stage=retrieve`, `retry_allowed=true` → 질의 분석·추천 검색·초안 생성 재실행 → `passed=true`, `finalization_reason=review_passed`.
2. `intent_mismatch`, `retry_stage=classify_intent` → 의도 분류·영화 검색·초안 생성 재실행 → 재시도 2회 후 `retry_allowed=false`, `finalization_reason=review_failed_safe_response`.

별도 실행에는 HTTP 429 후 규칙 검수·근거 기반 응답으로 전환한 기록도 있음. 검수 점수 100이나 `review_passed`만으로 모델 검수 성공 또는 사실 정확도를 단정하지 않음. `review_failed_grounded_recommendations` 상태도 있어 모든 실패가 동일한 안전 응답으로 끝난다고 표현하지 않음.

상세 페이지에 펼쳐 보는 실행 사례 두 개를 추가. 원문 로그·대화·사용자 정보·세션·호스트·프로세스·접속 경로 등은 공개하지 않음.
