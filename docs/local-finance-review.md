# 정책지원시스템 포트폴리오 검토

검토일: 2026-10-31

## 담당 범위와 공개 자료

사용자 확인: 차세대 지방재정관리시스템 전체 중 정책지원시스템 개발·구축 담당. 공개 기사와 이미지의 전체 서비스 규모를 개인 개발 실적으로 전환하지 않는다. 프로젝트 제목을 정책지원시스템 구축으로 명확히 했다.

- 사용자 제공 첫 공유 링크의 원문: https://zdnet.co.kr/view/?no=20230918182336 (2023-09-18). 이미지 설명은 종합지역현황 서비스 화면이며 비아이매트릭스 제공. 기사에서는 스마트빅보드 기능도 소개한다.
- 두 번째 원문: https://www.yna.co.kr/view/AKR20230825131300530 (2023-08-27). 행정안전부 제공 정책지원시스템 개요도.
- 정부 원문 대조: https://www.nabis.go.kr/policyDetailView.do?gbnCode=P50&menucd=20&poIdx=12454&refCode=20 . 행정안전부가 작성한 서비스 개시 보도자료. NABIS에서 공공누리 제1유형으로 안내한다.
- 이미지는 기사 제공 서버의 원본 URL을 참조하고 기사·이미지 제공처를 표시한다. 뉴스 이미지를 개인 구현 화면으로 표기하지 않는다.

## 사용자지침서 대조

로컬 `사용자지침서_정책지원_유사자치단체유형관리.pdf` 21쪽 텍스트를 추출해 확인했다. 작성 이력에 사용자 이름과 2023-06-28 매뉴얼 작성 기록이 있다. 메뉴는 11개다. 같은 폴더에 원본 HWP와 기준·결과 PDF가 존재하는 것도 확인했다. 내부 원본, 화면 ID, 스키마·테이블명, 실제 화면과 데이터는 공개 저장소에 복사하지 않았다.

- 기준: 자치단체 등급·행정단위, 지표 구분·항목, 수작업 지표와 평가방법 정보.
- 산출: 연도·차수, 지표 선택·가중치 합계 100%, 적용과 저장의 구분.
- 상태: 확정 차수는 적용 제한, 유형분류연도별 한 차수만 확정.
- 비교: 전문기관 엑셀 양식 확인·저장, 산출 자료와 점수·등급 비교, 자치단체명 기준 매칭.
- 평가방법 등록 화면은 문서상 정보 저장·조회 기능이다. 모든 평가방법이 동적 실행되는 엔진을 개발했다고 확대하지 않는다.
- 비교와 확정은 저장 결과를 사용하는 별도 업무다. 비교 완료가 확정의 필수 선행 조건이라고 표현하지 않는다.

## 표현 범위

- 200여 화면은 공통 모델·개발 규칙 적용 범위. 전부 단독 개발한 화면 수로 쓰지 않는다.
- 유형분류 11개 화면은 유형분류·재정위기관리 심화 화면 합계 30여 본의 일부다. 두 수치를 합산하지 않는다.
- 통계청·한국은행 API 기반 통계·BI 개발은 사용자 진술에 근거한다. 해당 화면 원본은 보안상 게시하지 않고 구현 범위를 설명한다.
- 유형분류와 재정위기관리의 전체 입력을 외부 API로 단정하지 않는다.
